# Greenfield versus incumbent decisions

Before comparing candidates, record:

- the implementation target;
- whether it is greenfield, incumbent, migration, or reusable guidance;
- which supplied repositories are targets and which are evidence;
- architecture choices already settled.

## Evidence weighting

| Evidence | Greenfield target | Incumbent target |
| --- | --- | --- |
| Existing package usage | Ergonomics and failure evidence | Consistency and migration constraint |
| Existing generation or build tools | Operational-cost evidence | Possible reduction in adoption cost |
| Official ecosystem integration | High weight | High weight balanced against migration |
| Team familiarity | Adoption-cost input | Adoption and migration input |
| General technical capability | High weight | High weight but not decisive alone |
